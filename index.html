1. Project Overview & Exact Flow

Is project ka maqsad yeh sikhna hai ki HTTP Cookies kaise kaam karti hain: unhe server par kaise Set kiya jata hai, browser kaise unhe automatically har request ke sath wapas bhejta hai, server par unhe kaise Parse aur Read karte hain, aur Clear kaise karte hain.

Complete Request-Response Lifecycle Flow:

Browser ➡️ Route (auth.routes.js) ➡️ Middleware (auth.middleware.js) ➡️ Controller (auth.controller.js) ➡️ EJS View / Response
  • Step 1 (Login): User /login form submit karta hai (POST request).
  • Step 2 (Set Cookie): Controller res.cookie("IsLoggedIn", "true", { httpOnly: true }) execute karta hai. Response header mein Set-Cookie browser ko milta hai.
  • Step 3 (Store in Browser): Browser is cookie ko apne storage mein store kar leta hai.
  • Step 4 (Next Request): Jab user / ya /dashboard open karta hai, browser automatically request header ke sath Cookie: IsLoggedIn=true; ... bhejta hai.
  • Step 5 (Parse via Middleware): cookie-parser raw cookie string ko parse karke req.cookies object banata hai.
  • Step 6 (Auth Protection): isAuthenticated middleware check karta hai: Agar req.cookies.IsLoggedIn === "true" toh next(), warna /login par redirect.
  • Step 7 (Logout): User Logout click karta hai toh res.clearCookie() se browser se cookie delete hoti hai.
⚠️ Educational Note: Is project mein humne client-side demo authentication kiya hai (IsLoggedIn="true"). Real-world production apps mein password ko bcrypt se hash karke database (MongoDB/PostgreSQL) mein verify kiya jata hai aur secure cryptographically signed sessions ya JWT use kiye jaate hain.

4. Step 2: Main Server Configuration (server.js)

import express from "express";
import cookieParser from "cookie-parser";
import { authRouter } from "./routes/auth.routes.js";

const app = express();
const PORT = 3000;

app.set("view engine", "ejs");
app.use(express.static("public"));
app.use(express.urlencoded({ extended: true }));
app.use(cookieParser());
app.use(authRouter);

app.listen(PORT, () => {
  console.log(`Server started: http://localhost:${PORT}`);
});

Line-by-Line Explanation:

  • import express from "express"; — Express web framework ko import karta hai jisse server aur HTTP routes banaye jaate hain.
  • import cookieParser from "cookie-parser"; — Incoming requests ke Cookie HTTP header ko parse karke req.cookies JavaScript object mein convert karta hai.
  • import { authRouter } from "./routes/auth.routes.js"; — Modular router file ko import karta hai jisme authentication aur pages ke routes define hain.
  • const app = express(); — Express application ka instance banata hai.
  • app.set("view engine", "ejs"); — Express ko batata hai ki HTML templates render karne ke liye EJS engine ka use karo. Default views folder views/ hota hai.
  • app.use(express.static("public")); — public/ folder ke static assets (jaise style.css) ko directly browser ke liye serve karta hai.
  • app.use(express.urlencoded({ extended: true })); — HTML form ke POST request data ko parse karke req.body mein provide karta hai.
  • app.use(cookieParser()); — cookie-parser middleware ko global level par activate karta hai.
  • app.use(authRouter); — authRouter ke sabhi routes ko main app ke sath attach karta hai.
  • app.listen(PORT, ...); — Port 3000 par incoming requests listen karne ke liye server start karta hai.

5. Step 3: Centralized Routing (routes/auth.routes.js)

import { Router } from "express";
import {
  getLogin,
  getRegister,
  postRegister,
  postLogin,
  getHome,
  getDashboard,
  setTheme,
  logout,
  clearCookies
} from "../controllers/auth.controller.js";
import { isAuthenticated } from "../middleware/auth.middleware.js";

const router = Router();

router.get("/register", getRegister);
router.post("/register", postRegister);

router.get("/login", getLogin);
router.post("/login", postLogin);

router.get("/", isAuthenticated, getHome);
router.get("/dashboard", isAuthenticated, getDashboard);
router.post("/theme", isAuthenticated, setTheme);
router.post("/logout", logout);
router.post("/clear-cookies", clearCookies);

export const authRouter = router;

Function & Line Definitions:

  • Router() — Express ka mini router object banata hai jisse related endpoints ko alag file mein organize kar sakte hain.
  • router.get("/register", getRegister) — Jab user /register URL par browser se aata hai toh registration page render hota hai.
  • router.post("/register", postRegister) — Registration form submit hone par user ka form data process karta hai.
  • router.get("/login", getLogin) — Login page render karta hai. Agar browser mein saved email hai to usko input field mein pre-fill karta hai.
  • router.post("/login", postLogin) — Login form submit hone par login cookie aur remember-me check karke cookie set karta hai.
  • router.get("/", isAuthenticated, getHome) — Protected Route: Pehle isAuthenticated middleware check karta hai; pass hone par hi getHome chalega.
  • router.get("/dashboard", isAuthenticated, getDashboard) — Protected Route: Live browser cookies dekhne ke liye Cookie Dashboard render karta hai.
  • router.post("/theme", isAuthenticated, setTheme) — User ki theme preference (light/dark) cookie mein save karta hai.
  • router.post("/logout", logout) — User ka session clear karke login page par redirect karta hai.
  • router.post("/clear-cookies", clearCookies) — Dashboard se ek click par saari cookies reset karta hai.

6. Step 4: Authentication Middleware (middleware/auth.middleware.js)

export const isAuthenticated = (req, res, next) => {
  const isLoggedIn = req.cookies.IsLoggedIn;
  console.log("IsLoggedIn:", isLoggedIn);
  
  if (isLoggedIn === "true") {
    return next();
  }
  return res.redirect("/login");
};

Function & Line Definitions:

  • req.cookies.IsLoggedIn — cookie-parser dwara parsed cookies mein se IsLoggedIn cookie ki value read karta hai.
  • if (isLoggedIn === "true") return next(); — Agar cookie match karti hai, toh next() call hota hai jo request ko controller handler tak aage jane deta hai.
  • return res.redirect("/login"); — Agar cookie missing hai ya false hai, toh browser ko turant /login page par redirect kar deta hai taaki unauthorized user page access na kar sake.

4) postLogin

export const postLogin = (req, res) => {
  const { email, password, remember } = req.body;

  // 1. Agar 'Remember me' click hua hai toh SARE COOKIES ACTIVE KARO!
  if (remember) {
    let allVisits = {};
    try {
      allVisits = req.cookies.allVisits ? JSON.parse(req.cookies.allVisits) : {};
    } catch (e) {
      allVisits = {};
    }

    let visits = (allVisits[email] || 0) + 1;
    allVisits[email] = visits;

    const maxAge = 7 * 24 * 60 * 60 * 1000; // 7 days active

    // SARE COOKIES EK SAATH ACTIVE:
    res.cookie("IsLoggedIn", "true", { httpOnly: true, maxAge });
    res.cookie("userEmail", email, { maxAge });
    res.cookie("remember", "true", { maxAge });
    res.cookie("theme", req.cookies.theme || "light", { maxAge });
    res.cookie("visits", String(visits), { maxAge });
    res.cookie("allVisits", JSON.stringify(allVisits), { maxAge });

    return res.redirect("/");
  } else {
    // 2. Agar 'Remember me' click NAHI hai:
    // userEmail, theme aur IsLoggedIn cookies mein dikhega:
    res.cookie("IsLoggedIn", "true", { httpOnly: true });
    res.cookie("userEmail", email);
    res.cookie("theme", req.cookies.theme || "light");

    // Lekin visits aur remember cookies set nahi hongi:
    res.clearCookie("remember");
    res.clearCookie("visits");
    res.clearCookie("allVisits");

    return res.redirect("/");
  }
};
  • Remember me Clicked (Checked): IsLoggedIn, userEmail, theme ke sath-sath visits aur remember cookies bhi active ho kar 7 days ke liye browser mein store hoti hain.
  • Remember me Unchecked (Not Clicked): userEmail, theme aur IsLoggedIn toh browser mein dikhti hain, lekin visits aur remember cookies set nahi hoti hain (visit counter inactive rehta hai).

5) getHome (Conditional Visits Logic)

export const getHome = (req, res) => {
  const email = req.cookies.userEmail || "";
  const theme = req.cookies.theme || "light";

  let visits = 0;

  // Check: Agar check box click hua tha tabhi visits cookie set hogi
  if (req.cookies.userEmail) {
    let allVisits = {};
    try {
      allVisits = req.cookies.allVisits ? JSON.parse(req.cookies.allVisits) : {};
    } catch (e) {
      allVisits = {};
    }

    visits = allVisits[email] || 0;

    if (req.cookies.skipVisit) {
      res.clearCookie("skipVisit");
    } else {
      visits = visits + 1;
      allVisits[email] = visits;
      res.cookie("visits", String(visits));
      res.cookie("allVisits", JSON.stringify(allVisits));
    }
  }

  return res.render("home", { 
    email: email || "Guest (Checkbox Not Clicked)", 
    visits: visits, 
    theme 
  });
};
  • Check Box Click Verification: visits cookie ab sirf aur sirf tabhi create aur save hoti hai jab login ke waqt "Remember me" click kiya gaya ho.
  • Agar check box click nahi kiya gaya toh browser mein userEmail, visits, aur allVisits cookies set nahi hoti.

6) getDashboard

export const getDashboard = (req, res) => {
  return res.render("dashboard", { cookies: req.cookies });
};
  • Kaam: dashboard.ejs ko browser se aayi sabhi parsed cookies (req.cookies) pass karta hai taaki live table format mein cookies inspect ki ja sakein.

7) setTheme

export const setTheme = (req, res) => {
  const { theme } = req.body;
  res.cookie("theme", theme);
  res.cookie("skipVisit", "true");
  return res.redirect("/");
};
  • Kaam: Form se select hui theme ("light" ya "dark") ko cookie mein set karta hai.
  • res.cookie("skipVisit", "true") — Temporary flag set karta hai taaki redirect hone par home page visit count na badhaye.

8) logout

export const logout = (req, res) => {
  res.clearCookie("IsLoggedIn", { httpOnly: true });
  return res.redirect("/login");
};
  • Kaam: Sirf IsLoggedIn session cookie ko delete karta hai. User ka userEmail aur allVisits history safe rehti hai taaki next time wahi email aane par uska purana count recall kiya ja sake.

9) clearCookies

export const clearCookies = (req, res) => {
  res.clearCookie("IsLoggedIn", { httpOnly: true });
  res.clearCookie("userEmail");
  res.clearCookie("visits");
  res.clearCookie("allVisits");
  res.clearCookie("theme");
  res.clearCookie("skipVisit");
  return res.redirect("/dashboard");
};
  • Kaam: Testing aur demo ke liye ek hi click mein saari cookies (session, visits, theme, emails) wipe out kar deta hai.
